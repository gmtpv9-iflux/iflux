# 7. RUNTIME EXECUTION LOOP (FROM FILE 08)

## 7.1 Boot sequence

```text
INIT DOM
→ mount all screens
→ hydrate mock entities
→ attach entity store
→ start WSS simulator
→ start diff engine
→ enable pulse engine
```

---

## 7.2 Update loop

```text
WSS EVENT
→ map event → entity key
→ patch entity store
→ find DOM binding
→ update component only
→ trigger pulse (if allowed)
```

---

## 7.3 Priority handling

| Event type         | Priority |
| ------------------ | -------- |
| snapshot           | highest  |
| reconnect override | highest  |
| WSS tick           | medium   |
| UI local state     | lowest   |

# 11. SANDBOX RENDER GUARANTEE

## 11.1 What MUST be true

* All screens exist in DOM simultaneously
* All widgets mounted at boot
* Entity store drives all updates
* No navigation dependency
* No lazy screen loading

---

## 11.2 What MUST NOT happen

* no SPA routing required for sandbox
* no backend dependency
* no missing screen placeholder
* no “wait screen load”
