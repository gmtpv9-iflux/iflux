## 0.2 Four-layer model (09 internal structure)

```text
LAYER 1 — REGISTRY        → what exists (screens, widgets, components, routes)
LAYER 2 — DATA CONTRACT   → entity/mock shape (mirror 05 §0.5) + prefetch REST
LAYER 3 — ORCHESTRATION   → sandbox binding of 08 (FSM, subscription, router, mount)
LAYER 4 — CONTROL PLANE   → dev tools (pause, inject, replay, introspection)
```

**Quy tắc:** Layer 3 **reference** 08/05 — không invent engine logic mới. Layer 4 **chỉ** áp dụng sandbox, không bắt buộc production FE UI.

* **Một** global Entity Store (05 §0.5) — widget **share**, **không isolate**
* Reconnect: **không** unmount screen / **không** full tree rerender (05 §1.2)

# LAYER 3 — RUNTIME ORCHESTRATION (sandbox binding of 08)

> Chi tiết engine: **08 §1–§9**. Phần này khóa **hành vi sandbox** và **subscription graph**.

## 3.1 Widget lifecycle FSM

```text
INIT → HYDRATE → MOUNT → STREAM → PATCH → SUSPEND ⇄ RESUME
                              ↓ reconnect (05 §1.2)
                         DISCARD_WSS → SNAPSHOT_OVERRIDE → PATCH → STREAM
DESTROY  ← chỉ logout / app teardown (không dùng khi reconnect)
```

| State | Meaning |
| --- | --- |
| INIT | Widget registered; no DOM |
| HYDRATE | Bind entity snapshot subset |
| MOUNT | Attached to active screen |
| STREAM | Subscribed to channels (§3.2) |
| PATCH | Apply entity diff → component zones |
| SUSPEND | Screen inactive; **keep** entity subscription optional (policy: unsubscribe to save sim traffic) |
| RESUME | Remount from cached entity; resubscribe |

**Reconnect:** widget **không** re-INIT; global store override → widget PATCH only.

---

## 3.2 Subscription graph (CRITICAL)

```text
Widget → entity_key selectors → WSS / REST / Push channels
```

| Widget | Entity keys | Channels (Contract §4.3) |
| --- | --- | --- |
| W-MARKET | `market:*`, `entities.market` | `index:sector:*` (VNINDEX path via snapshot + index_update) |
| W-MOVERS | `stock:{ticker}` per row | `stock:*` |
| W-SECTOR | `sector:{id}` | `index:sector:*` |
| W-FLOW | `flow:{subject}` | `flow:*` |
| W-STOCK | `stock:{ticker}` | `stock:{ticker}`, `flow:sector:{id}:*` |
| W-WATCHLIST | `stock:{ticker}`, sticker fields | `stock:*`, `sticker:user:{user_id}` |
| W-ALERT | `alerts[]` | **Push**, `user-events` — **excluded** market WSS (05 §7.3) |
| W-SEARCH | — | REST only |

**Rule:** No subscription graph entry → sandbox **MUST NOT** route simulated events to that widget.

---

## 3.3 Event router contract

```text
event → normalize → (priority queue §3.6) → entity patch → diff_keys[]
     → fanout to widgets subscribed to those keys
     → component zone patch (06)
```

**Fanout:** one entity field change → **all** widgets bound to that key (e.g. HPG price → W-MOVERS + W-WATCHLIST if listed).

**Dedup:** `event_id` per stream (INV-E01) — 05 §9.2.

---

## 3.4 Collapse / batch rules (ANTI-FLAP — quote 05)

| Question | Rule (SoT) |
| --- | --- |
| 20× `price_update` / 200ms | Keep **latest per** `diff_key` in batch window (05 §9.3, 08 §2.4) |
| `flow_update` + `price_update` same ticker | Independent fields — merge per field, no order dependency |
| Snapshot mid-burst | **Discard** queued WSS → snapshot override → then accept new WSS (05 §1.2 steps 1–4) |
| Reconnect window | **No queue replay** of discarded WSS |

---

## 3.5 Screen mount contract

| Screen | Mount mode | Prefetch | Subscribe timing |
| --- | --- | --- | --- |
| SCR-001 Home | **eager** | §2.2 all blocks | on mount |
| SCR-002 Stock | **lazy** | ticker snapshot | on mount + `stock:{t}` |
| SCR-003 Sector | **lazy** | sector detail | on mount |
| SCR-004 Watchlist | **batch hydrate** | watchlist + stocks | on mount |
| SCR-005 Alerts | **lazy** | GET alerts | Push registration |
| SCR-006 Search | **on query** | debounced REST | no WSS until result open |

**Screen transition:**

* Entity store: **preserve** globally
* Scroll: write/read `ui.scroll[screenKey]` on leave/enter (05 §1.4)
* Widget reuse: same `StockRow` component type across W-MOVERS / W-WATCHLIST / sector list (06 §0.3)

---

## 3.6 Render priority engine (sync 08 §9.2)

| Priority | Type | Preempts |
| --- | --- | --- |
| **P0** | Snapshot override | all lower |
| **P1** | Reconnect discard window | P2–P4 |
| **P2** | Push / `user-events` / 409 sync response | P3–P4 |
| **P3** | WSS market (`price`, `index`, `flow`, `sticker`) | P4 |
| **P4** | UI chrome / pulse animation only | — |

Same-tick conflict: execute highest priority first; lower priority frames in same 200ms window **dropped** if superseded by P0–P2.

---

## 3.7 Partial state propagation

| Update level | Propagation |
| --- | --- |
| Field (`stock:HPG:price`) | Zone C (+ pulse) on **each** row showing HPG |
| Entity (`stock:HPG` bulk) | All widgets with `stock:HPG` subscription |
| Collection (watchlist order) | W-WATCHLIST full list patch — **no** other screens unless shared ticker |

**Overlap rules (06 §5.3–5.5):**

* STALE + pulse: **both** apply until DEGRADED
* DEGRADED + WSS: **ignore** RT visual update (05 §9.4)
* PARTIAL + reconnect: filled fields preserve; empty fields skeleton until patch

---

## 3.8 Edge orchestration matrix

| Combo | UI | Data |
| --- | --- | --- |
| ERROR + reconnect | indicator + retry | discard → snapshot |
| DEGRADED + user opens Watchlist | full access; frozen prices | no pulse |
| 409 + W-WATCHLIST mounted | modal; toast after GET | server list overwrite |
| PUSH during screen transition | queue toast; dedup | apply alert state |
| SCN-03 + SCN-02 race | reconnect wins (P1 > P3) | burst discarded in window |

# 5. BOOT SEQUENCE & FAILURE MODES

## 5.1 Boot sequence

```text
1. load mock schema (align 05 §0.5)
2. init global entity store
3. register widgets (Layer 1 table)
4. build subscription graph (§3.2)
5. mount SCR-001 (or route default)
6. hydrate snapshot
7. start event engine (08)
8. attach DOM renderer (06 rules)
9. enable control plane (Layer 4)
```

## 5.2 Failure modes

| Case | Behavior |
| --- | --- |
| Missing widget registry entry | Safe mode: SCR-001 only + error panel (§5.3) |
| Missing entity field | Render `—` (06 §5.4) — no fake `0` |
| Missing scenario handler | Disable that SCN button; log warning |
| Broken subscription graph | Stop WSS routing; show graph error |
| Diff apply failure | Freeze affected widget; preserve store |

## 5.3 Safe mode

If registry incomplete:

* fallback **SCR-001** only
* disable live WSS simulation
* show **registry error panel** listing missing IDs from §6 matrix
