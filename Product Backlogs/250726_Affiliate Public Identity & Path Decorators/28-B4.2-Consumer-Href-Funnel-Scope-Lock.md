## 1. Mục tiêu

Biến identity decoration từ *"developer phải nhớ gọi Writer"* → **default behavior mọi public href**.

```text
Entity/SEO URL Factory (IfluxSeoUrl)  →  canonical only
                    ↓
Identity Href Resolver (IfluxHref)    →  Routes.href / forCanonical
                    ↓
ShellUrlWriter.decorate()
                    ↓
/IFLYZ2NC/co-phieu/MSN
```

**SeoUrl không sở hữu identity.** Cấm `SeoUrl.*Href({ identity: true })`.

---

## 2. API duy nhất — navigation href

| API | Input | Output |
|-----|-------|--------|
| `IfluxHref.forCanonical(canonical)` | canonical path | decorated href |
| `IfluxRoutes.href(canonical)` | alias → `IfluxHref.forCanonical` | decorated href |
| `IfluxRoutes.to(routeKey)` | route key | decorated (unchanged) |
| `IfluxShellUrlWriter.navigate(canonical)` | programmatic nav | decorated (unchanged) |

**Cấm consumer gọi `decorate()` trực tiếp** (MR-1).

## 3. Migration pattern (B4.2.2)

```javascript
// Trước
href = IfluxSeoUrl.stockHref('MSN');

// Sau
href = IfluxHref.forCanonical(IfluxSeoUrl.stockHref('MSN'));
// hoặc
href = IfluxRoutes.href(IfluxSeoUrl.stockHref('MSN'));
```

Local helper `idHref(c)` được phép trong module — phải delegate `IfluxHref.forCanonical`.
