## 2. Migration pattern

```text
Programmatic nav  → IfluxHref.navigate(canonical) | IfluxShellUrlWriter.navigate(canonical)
DOM href          → IfluxHref.forCanonical(canonical)  (B4.2)
Search Enter key  → IfluxHref.followHref(href)         (normalize + navigate)
Route key         → IfluxRoutes.to(key)                (B3 funnel)
```

Fallback `location.href` chỉ còn trong helper khi Writer/Href chưa load (pre-shell edge).
