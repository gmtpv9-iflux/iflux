## 1. Vì sao phải chốt contract trước E2?

E1 (`WidgetRegistryReader`) **có thể làm song song** — không phụ thuộc index.

| Hiện tại (coupling) | Ý nghĩa thực |
|---------------------|--------------|
| `entitlements.html` → `hydratePlacementFromPublished()` | GET PagePublished → ghi vào PageSettingsStore |
| `listEnabledPlacementWidgets()` | Đọc `layoutSlots` where `enabled`, intersect L4 |

→ Filter "Chỉ Widget đang Bật" **đã dùng dữ liệu Published** — nhưng qua **Placement Store cache**.  
Backend index phải **reproduce cùng semantics**, không phải chỉ "aggregate placements".

Nếu không chốt → làm xong E2 mà filter lệch row count = **chưa xong thật**.

## 3. Index Builder Algorithm (parity với code cũ)

Source: `page_current_versions` + join `page_published_versions.artifact`.

For each published page `P`:

1. Parse `artifact.placements[]`
2. Include placement when:
   - `placement.widgetId` truthy
   - `placement.enabled !== false`  ← same as `publish-pipeline.js:103` and `page-settings-store.js:106`
3. Add `widgetId` to `byPage[P.page_key]` (dedupe per page)
4. Union all into `allEnabled` (global dedupe, sort lexicographic)

**Page universe:** All rows in `page_current_versions` (pages that have ever been published).  
Không dùng DEFAULT_PAGES nếu page chưa publish → không có artifact → không có widget (same as hydrate 404 skip).

### L4 intersection (parity)

Code cũ (`page-settings-catalog.js:728-735`):

```javascript
allWidgetIds().forEach(function (id) { l4[id] = true; });
// ...
if (!l4[slot.widgetId]) return;
```

**Rule:** `allEnabled` chỉ gồm widgetId **tồn tại trong Widget Registry / L4 catalog** tại thời điểm build.

Implementation: server loads L4 widget id set từ published widget artifacts OR shared allowlist table — **E2 implementer must use same source as `PlatformLayersWidgets.widgetIds()`**.

> Nếu server chưa có L4 id list: index builder gọi `widget_current_versions` keys as proxy — document in E2 implementation note.

### Title / description (not in index response)

Index response **chỉ widgetIds** — không embed title/description.

Client (`PlacementWidgetIndexReader` + matrix UI):

```javascript
// Parity with listEnabledPlacementWidgets return shape
entries = allEnabled.map(function (id) {
  var copy = WidgetRegistryReader.get(id); // or sync cache after load
  return { id: id, title: copy.title || id, description: copy.description || '' };
});
```

→ Permission **reference** L4 metadata qua WidgetRegistryReader — **không** PageSettingsCatalog.
