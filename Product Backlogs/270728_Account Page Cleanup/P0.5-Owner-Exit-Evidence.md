## 1. Mục tiêu

Mỗi vùng UI trên trang Tài khoản có **đúng một entry `init()`** bind DOM. Boot **không** gọi nhiều module cùng chạm một selector.

| Vùng | Owner (global) | File | DOM scope |
|------|----------------|------|-----------|
| **Sidebar** | `IfluxProfileSidebar` | `profile-bind.js` | `[data-ifx-profile-sidebar]` · hero · plan · edit/save |
| **Affiliate** | `IfluxProfileAffiliatePage` | `profile-affiliate.js` | `#tab-affiliate` · ref-link · payout · bảng |
| **Thanh toán** | `IfluxProfilePaymentPage` | `profile-payment-page.js` | `#tab-payment` · `#ifx-mine-payment-form` |
| **Quyền riêng tư** | `IfluxProfilePrivacyPage` | `profile-privacy-page.js` | `#tab-privacy` |
| **Bảo mật** | *(static P3)* | `profile.html` | `#tab-security` — banner «Sắp có» · chưa API |

**Boot** (`account-feature-boot.js`) chỉ:

```javascript
IfluxProfileSidebar.init();
IfluxProfileAffiliate.init();
IfluxProfilePaymentPage.init();
IfluxProfilePrivacyPage.init();
```

## 3. Thay đổi đã ship

### 3.1 `profile-bind.js` → Sidebar Owner

- Export `IfluxProfileSidebar` · alias `ProfileBind` (widget/dashboard legacy)
- Gom edit/save sidebar từ `account-feature-boot.js`
- Gọi `IfluxProfileAvatar.initOwn()` **một lần** trong owner
- **Gỡ** bind `#ref-link` / `#ref-code` (chuyển Affiliate owner)
- Scope bind trong sidebar khi có `[data-ifx-profile-sidebar]`

### 3.2 `profile-affiliate.js` → Affiliate Owner

- Own ref-link · ref-code · copy nút (`data-ix-copy-ref`)
- Không phụ thuộc `ProfileBind.referralLinkValue`
- Alias `IfluxProfileAffiliatePage`

### 3.3 `profile-payment-page.js` *(mới)* → Payment Owner

- Extract từ `profile-my-page.js`
- Account boot **không** load `profile-my-page.js`
- Hub legacy vẫn delegate qua `IfluxProfileMyPage` → `IfluxProfilePaymentPage`

### 3.4 `account-feature-boot.js`

- Gỡ init: `PatternUserProfile` · `IfluxProfilePage` · `IfluxProfileMyPage` · duplicate Avatar/Bind
- Gỡ sidebar edit/save inline
- Gỡ script `pattern-user-profile.js` khỏi boot (copy ref → Affiliate owner)
