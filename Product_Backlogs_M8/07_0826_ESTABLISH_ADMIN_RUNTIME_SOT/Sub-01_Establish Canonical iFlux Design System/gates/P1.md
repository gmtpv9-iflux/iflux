### Token SoT Amendment (2026-08-28 — Token 03A)

Supersedes P1 “one physical token source root”. Breakpoint lock (§0.1) and generated-readonly remain.

```text
ONE TOKEN = ONE OWNER = ONE SOURCE DEFINITION
ONE CANONICAL COMPILER
MULTIPLE SOURCE ROOTS ALLOWED BY OWNER
```

Canonical Token SoT is one governed token system — not one physical directory.

1. `design_system/tokens/source/*.json` — writable source **only** for Global Design System tokens.
2. Lower-layer sources live with their owners (`platform/<id>/tokens/source/`, `modules/<domain>/tokens/source/`). Registered in `design_system/tokens/registry.json`. Unregistered JSON is not SoT.
3. `design_system/scripts/build-tokens.mjs` is the only compiler. It ingests every **active** registered root and emits readonly generated artifacts beside that owner. It must not dump lower-layer tokens into Global `primitives.css`.
4. Duplicate `--ifx-*` names across registered sources = compile failure.
5. Runtime leftover Admin/User_Web `:root` copies are not canonical source.
