## 4. Bổ sung 1 — Viewport selector (iframe isolation)

Nút: `AUTO | 360 | 480 | 768 | 1024 | 1280 | 1440`

- AUTO = logical width = viewport trình duyệt hiện tại.
- Nút số = `iframe` width đúng px đó → CSS `@media` trong iframe nhận viewport thật.
- 1280 / 1440: scale visual nếu vùng sandbox hẹp hơn; `window.innerWidth` trong iframe vẫn đúng số nút.
- Hiển thị đồng thời: Selected viewport · Actual preview width · Active breakpoint · breakpoint markers.
- JS chỉ chọn viewport, hiện số, điều khiển sandbox. Layout = `foundation/layout.css` mobile-first.
