## 2. Quyết định trong P2 (không mở lại Solution)

1. **Canonical-only khi REUSE:** các twin `.ix-*`, alias không prefix (`.ix-h1`, `.ix-card-title`…), Domain Matrix v1 aliases (`--ifx-label-l`, `--ix-font-size-base`…), component bridges (`.ix-btn`, `.ix-table`…) và shell hooks (`.ifx-topnav-*`) **không carry** sang canonical — chúng ở lại legacy bundle (sẽ FROZEN sau P8), phần component/platform xử lý ở P3+/downstream.
2. **Responsive semantic spacing viết lại mobile-first** — legacy dùng `max-width`; canonical dùng base + `min-width` literal 3 mốc (768/1024/1440). Computed value từng viewport giữ nguyên parity:

| Token | BASE | ≥768 | ≥1024 | ≥1440 |
|---|---|---|---|---|
| `--ifx-space-container` | 16px | 20px | 24px | 32px |
| `--ifx-space-section` | 48px | 56px | 64px | 80px |
| `--ifx-space-page` | 64px | 64px | 80px | 96px |
| `--ifx-grid-gutter` / `--ifx-container-margin` | 16px | 24px | ← | ← |
| `--ifx-inset-panel` | 16px | 20px 24px | ← | ← |
| `--ifx-inset-dialog` | 16px | 24px | ← | ← |

3. **`.ifx-container-max` (opt-in):** token `--ifx-size-container-max: 1280px` có trong SoT nhưng legacy chưa có class consumer → canonical thêm 1 modifier opt-in (1 dòng), demo ngay trong playground. Container mặc định vẫn full-width như hành vi legacy.
4. **Typography responsive = N/A** (ghi rõ trên playground): contract typography dùng fixed token scale, không đổi size theo breakpoint — đúng ghi chú trong foundation đang chạy, không tạo demo giả.
5. **Playground full-bleed:** đặt ngoài `.sb-main` (vốn giới hạn 1280px) để demo container/max-width theo viewport thật.
6. **Theme adapter không đụng DOM ngoài `data-theme`:** không auto-inject nút toggle (legacy làm — đó là việc platform); sandbox tự gắn nút gọi `IfxTheme.toggle()`.
