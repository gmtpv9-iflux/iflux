## 2. HỆ THỐNG CHUYỂN ĐỘNG (MOTION)

### 2.1 Motion hierarchy

1. **Pulse** (cao nhất) — price/index cell  
2. **Transition** — screen/nav  
3. **Hover** — web only  
4. **Skeleton shimmer** — LOADING only  

Pulse **override** hover/transition **trong cùng cell** — không override global degraded freeze.

### 2.2 Real-time rules

| Effect | Rule |
|---|---|
| **Pulse** | 500ms ease-out; restart if tick < 500ms; green up / red down |
| **Stale** | No motion — opacity 0.6 only |
| **Degraded** | All motion off globally |
| **Reconnect** | Reset all pulse timers (05 §1.4) |

### 2.3 Motion conflict (animation-only)

| Xung đột | Thắng |
|---|---|
| Pulse + Hover | Pulse |
| Pulse + Transition | Pulse |
| Degraded + anything | Degraded (motion off) |
| Reconnect + Pulse | Reset pulse |

## 3. HỆ THỐNG BỐ CỤC (LAYOUT)

### 3.1 Grid

* **Web:** 12 columns, gutter 24px, max-width **1440px** (app content); marketing pages có thể 1120px per `css.md`
* **Mobile:** single column stack, horizontal padding `space-4`

### 3.2 Density (GĐ1 — LOCKED)

| Mode | Trigger | Row height | Spacing scale |
|---|---|---|---|
| **Normal** | Default all screens | `row-h-normal` | 100% |
| **Compact** | Home Block B Top Movers only | `row-h-compact` | 100% |

> **Deferred GĐ2:** `Market Active (-20%)`, `Alert Mode (+10%)` — chưa có trigger trong File 05; không implement GĐ1.

### 3.3 Widget rules

* Card-based; `radius-md`; no free-floating; no overlapping **content** (pulse layer excepted — §3.4)
* Widget header: Semibold 14px Navy; min-height `card-min-h`

### 3.4 Z-index scale (Layer Stack — BẮT BUỘC)

| Layer | Token | z-index | Ví dụ |
|---|---|---|---|
| Base / page | `z-base` | 0 | Background, grid |
| Row content | `z-content` | 1 | Text, numbers |
| Pulse overlay | `z-pulse` | 2 | Background flash trong price cell — **không che text** |
| Stale warning icon | `z-warning` | 3 | Icon 12px cạnh ticker |
| Hover highlight | `z-hover` | 4 | Web row hover (web only) |
| Sticky sub-header | `z-sticky` | 100 | Section header trong list |
| Degraded banner | `z-degraded-banner` | 150 | Dưới nav, trên content (05 §10.3) |
| Site nav / top bar | `z-nav` | 200 | Khớp pattern `css.md` |
| Dropdown / float CTA | `z-dropdown` | 300 | Bridge float button |
| Modal / paywall | `z-modal` | 400 | Upgrade, 409 overlay |
| Toast | `z-toast` | 500 | Sync conflict toast |

**Quy tắc stacking trong Price Cell:**

```
[ z-content: price text ]
[ z-pulse: absolute inset-0 pointer-events-none ]  ← pulse không che text
[ z-warning: icon góc phải cell ]
```

**Cấm:** pulse `z-index` > warning icon; modal < toast.

### 3.5 Responsive breakpoint matrix (GĐ1 — LOCKED)

| Breakpoint | Viewport | Platform | StockRow layout |
|---|---|---|---|
| **BP-S** | ≤ 390px | Mobile app / narrow web | Zones **A + C + D** only; hide **B**, hide **E** |
| **BP-M** | 391–768px | Mobile web / tablet portrait | **A + C + D + E**; hide **B** (name) |
| **BP-L** | ≥ 769px | Web / tablet landscape | Full **A–E**; **B** visible on web lists |

**Column collapse rules (StockRow):**

| Zone | BP-S | BP-M | BP-L |
|---|---|---|---|
| A Ticker | 56px fixed | 64px | 64px |
| B Name | hidden | hidden | flex 1 |
| C Price | flex 1 min 72px | `price-col-w` | `price-col-w` |
| D % Chg | 56px | `chg-col-w` | `chg-col-w` |
| E Volume | hidden | `vol-col-w` | `vol-col-w` |

**WatchlistRow BP-S:** hide zone **G** (alert dot); zone **F** max 80px.

**SectorCard:** BP-S/BP-M = 1 column; BP-L = 2-col mini grid (§4.5).

**Component switch:** không đổi component type — chỉ **hide columns** + token widths; không fork `StockRowMobile` riêng.

### 3.6 Layer interaction rules (GĐ1 — LOCKED)

| Element | pointer-events | Click behavior |
|---|---|---|
| Pulse overlay (`z-pulse`) | **none** | Click passes through to row |
| Price / number text (`z-content`) | auto | Normal text selection off on RT cells |
| Stale warning icon (`z-warning`) | **none** | Decorative — click passes to row |
| Row container (StockRow) | auto | Tap → Stock Detail (05 §5.3) — **kể cả DEGRADED** |
| DegradedBanner | auto | Banner only — không block scroll content beneath |
| Hover highlight (`z-hover`) | none | Background only — row click unchanged |
| Modal / 409 overlay | auto | Blocks list interaction until dismiss |
| FlowBar segments | none | Row/panel click unchanged |

**Degraded mode navigation:** row **vẫn clickable**; chỉ freeze RT visual + motion (05 §10.3).

**Hover vs pulse:** hover background có thể hiện **dưới** pulse layer; pulse không nhận pointer events.

### 4.1 StockRow (base)

**Dùng tại:** Home Movers, Sector top stocks, Stock lists.

```
┌─────────────────────────────────────────────────────────────┐
│ [A: Ticker]  [B: Name optional]  [C: Price] [D: %] [E: Vol] │
└─────────────────────────────────────────────────────────────┘
```

| Zone | Width / flex | Align | Font | Content |
|---|---|---|---|---|
| **A** Ticker | 64px fixed | left, center-y | Be Vietnam Pro 14px Bold | `ticker` |
| **B** Name | flex 1 min 0 | left, center-y | 13px muted | optional web |
| **C** Price | `price-col-w` | right, baseline | Mono 15px Bold | `price` + color up/down |
| **D** Change % | `chg-col-w` | right, baseline | Mono 13px | `change_pct` |
| **E** Volume | `vol-col-w` | right, baseline | Mono 12px muted | abbreviated volume |

| Property | Value |
|---|---|
| Height | `row-h-normal` (compact variant: `row-h-compact`) |
| Padding | `space-3` vertical, `space-4` horizontal |
| Border bottom | 1px `--gray-200` |
| Pulse target | Zone **C** background only (`z-pulse` inset) |
| Tap target | Full row → Stock Detail (05 §5.3) |

**States:** Normal | Price-up/down (pulse) | Stale (opacity 0.6 row text) | Error (row `--state-error-bg`) | Degraded (no pulse, frozen colors)

#### 4.1.1 Render shape — overflow & truncation (LOCKED)

> FE **MUST NOT** invent ellipsis behavior — áp dụng đúng bảng zone.

| Zone | Overflow | Truncation | Format notes |
|---|---|---|---|
| **A** Ticker | hidden | none — max 4 chars expected | Uppercase; never wrap |
| **B** Name | hidden | `ellipsis` 1 line | Tooltip on hover (web) if truncated |
| **C** Price | hidden | none — mono shrink 0.9 max | Server-formatted number; no wrap |
| **D** % Chg | hidden | none | Always show sign (`+2.57%`) |
| **E** Volume | hidden | `ellipsis` if needed | **Abbrev only if API sends abbreviated** — không tự format VND |

**Global row rules:**

* `white-space: nowrap` on zones A, C, D, E
* `min-width: 0` on flex children (B, C when flex)
* Row height **fixed** per density token — content **never** expands row height
* Long price at BP-S: reduce mono to **13px** before truncating (min legible)

### 4.6 FlowBar / FlowPanel

```

```

| Property | Value |
|---|---|

**QUY tắc (05 alignment):**

## 5. HỆ THỐNG TRẠNG THÁI

### 5.1 UI states (IA §20 binding)

| State | Visual |
|---|---|
| LOADING | Skeleton `--skeleton-bg` shimmer 1.5s |
| READY | Full render |
| STALE | opacity 0.6 + warning icon |
| ERROR | `--state-error-bg` |
| DEGRADED | banner + motion off + frozen RT display |

### 5.2 Linear priority

`DEGRADED > ERROR > STALE > LOADING > READY`

Linear priority chọn **dominant chrome**. Combo chi tiết → §5.3.

### 5.3 State combination matrix (BẮT BUỘC)

| Combination | Visual behavior | Data behavior (05) |
|---|---|---|
| **STALE + price_up pulse** | Opacity 0.6 on text **+ pulse still runs** on price cell | Entity patched; stale from `meta.staleness_ms` |
| **STALE + STICKER update** | Badge updates immediately; row text stays 0.6 until fresh | sticker patch OK |
| **DEGRADED + WSS event** | **Ignore** visual RT update; no pulse | 05 §9.4 transport may stop; UI policy freeze |
| **DEGRADED + REST snapshot** | Banner stays; show `data_as_of`; no pulse | Snapshot override §0.5.3 |
| **ERROR + snapshot recover** | Clear error bg → READY; keep scroll | Silent snapshot success |
| **ERROR + user retry fail** | Stay ERROR | Show retry |
| **LOADING + reconnect** | Skeleton **only on empty** cells; filled cells preserve last value | 05 §1.4 preserve |
| **Pulse + STALE** | Pulse on price cell; stale opacity on same cell text layer above pulse | Both apply |
| **409 overlay + LOADING** | Local list overlay `z-modal`; toast after refresh | 05 §10.4 |
| **Degraded + user opens Watchlist** | Full access; frozen prices; no pulse | BR-CON-05 |

**Degraded wins motion.** Stale does **not** block pulse unless Degraded active.

### 5.4 Empty & partial data rendering (IA §20 — LOCKED)

| Case | Visual | Component |
|---|---|---|
| **EMPTY list** (0 stocks) | IA EMPTY — message + **một** CTA | Watchlist: "Thêm mã"; Movers: hide block |
| **Field null** (`price` missing) | Show **`—`** mono muted in cell | Zone C/D/E — không skeleton whole row |
| **Partial entity** (price ok, `sticker` null) | Price READY; badge slot **hidden** | WatchlistRow zone F collapsed |
| **Partial entity** (price ok, `flow` null) | FlowPanel show **`—`** + empty bar track | FlowBar grey track only |
| **Delayed hydration** (sticker arrives later) | Price renders first; badge **fade-in** 150ms once when field appears | No layout shift — reserve 0 width until data |
| **LOADING first paint** | Skeleton per **missing field** only | Filled fields from cache show last value (05 §1.4) |

**Cấm:** fake `0` hoặc `0%` khi field null — dùng **`—`** hoặc hide slot.

### 5.5 Multi-event same row (zone independence — LOCKED)

> Coalescing / batch: **05 §9.3** (200ms). DS chỉ khóa **visual zones độc lập**.

| Events cùng row | Zones affected | Rule |
|---|---|---|
| `price_update` + `sticker_update` | C + F | Patch độc lập; pulse **chỉ zone C** |
| `price_update` + stale flag | C + row opacity | Both apply (§5.3) |
| `flow_update` + `price_update` | Flow panel + row C | Independent components |
| Reconnect burst | all | Snapshot override trước; then accept new events (05 §1.2) |

## 1.1 Design Principles

Mười nguyên tắc chỉ đạo mọi quyết định thiết kế của iFlux. Khi xung đột giữa các nguyên tắc, ưu tiên theo thứ tự dưới đây.

| # | Nguyên tắc | Ý nghĩa với iFlux |
|---|---|---|
| 1 | **Consistency** | Cùng hành vi, cùng ngôn ngữ thị giác trên toàn hệ thống |
| 2 | **Clarity** | Dữ liệu tài chính phải rõ ràng — không bao giờ để người dùng đoán |
| 3 | **Hierarchy** | Thông tin quan trọng nhất luôn nổi bật trước |
| 4 | **Simplicity** | Chỉ hiển thị những gì người dùng cần ở thời điểm đó |
| 5 | **Predictability** | Người dùng không phải học lại hành vi của cùng một component |
| 6 | **Accessibility** | WCAG 2.1 AA tối thiểu. Màu sắc không phải là phương tiện thông tin duy nhất |
| 7 | **Performance** | Render nhanh là UX. Skeleton trước data, không để màn hình trắng |
| 8 | **Responsiveness** | Mobile-first. Mọi component đều có trạng thái responsive được định nghĩa |
| 9 | **Reusability** | Mỗi component giải quyết một vấn đề, giải quyết tốt, và tái sử dụng được |
| 10 | **Scalability** | Hệ thống phải mở rộng được mà không phá vỡ những gì đã có |

iFlux dùng mô hình 3 tầng: **Primitive → Semantic → Component-specific**.

```
├── Semantic Colors
│   Mang nghĩa, không phải màu vật lý
│   ├── Primary      — hành động chính, accent

│   border-default  — viền thông thường
│   border-strong   — viền nhấn mạnh, focus

├── Icon Colors
│   Kế thừa từ Text Colors theo ngữ cảnh
```

- Dark mode: định nghĩa đủ cả hai bộ token, không dùng opacity filter để giả dark mode

**Ranh giới Block vs Widget:**

| | Block | Widget |
|---|---|---|

## Wireframe Mapping Contract

UX Wireframe Specification **bắt buộc** gắn mapping Design System — Product Design không cần deliverable visual riêng ngoài wireframe + bảng dưới.

**Mỗi vùng wireframe (Block) một dòng:**

| Field | Mô tả | Ví dụ |
|---|---|---|
| `wireframe_block_id` | ID Block trên wireframe | `BLK-HOME-A` |
| `ds_tier` | Tầng DS | `Block` · `Widget` · `Domain` |
| `ds_item` | Tên item catalog | `Block A — Market Overview` |
| `ds_components[]` | Component con (GĐ1 tên LOCKED nếu có) | `MarketHeader`, `IndexCell` |
| `widget_type` | Chỉ khi deploy widget | `WGT-MKT-001` |
| `surface` | Surface Scope | `User App` |
| `states[]` | Subset State Model | `Default`, `Loading`, `Stale`, `Degraded` |
| `screen_ref` | Tham chiếu UI Flow | `05 §3 Block A` |

**Luồng tham chiếu:**

```
UI Flow (05) Screen + Block
    → Wireframe Spec + mapping table (trên)
        → DS Catalog (§560+) tier + item
            → GĐ1 §4 anatomy/style khi là Market Core
                → Implementation (code — ngoài phạm vi catalog)
```

**Quy tắc:**

1. Không invent tên component mới trên wireframe — chọn từ catalog hoặc đề xuất thêm vào đúng tầng.
2. Block wireframe (§13) trước Widget (§14) — Widget chỉ khi cần dashboard slot hoặc `widget_type`.
3. Market Core GĐ1: **bắt buộc** dùng tên §10 Market Core / §4 GĐ1.

## Nguyên tắc mở rộng

Khi cần thêm component mới:

1. Kiểm tra xem có thể tổ hợp từ component hiện có không
2. Nếu không — xác định nó thuộc tầng nào (Primitive → Block → Widget)
3. Định nghĩa đủ states, variants, và responsive behavior trước khi build
4. Không tạo component một mục đích sử dụng ở một nơi duy nhất — đó là Block hoặc Widget, hoặc thuộc UI Architecture
5. Ghi `surface` và tham chiếu GĐ1 nếu thuộc Market Core

```
  Basic Components + Form Controls + Navigation + Feedback

  Data Display + Data Visualization foundation

Phase 4 — Domain
  Domain Components (Market Core GĐ1 trước) + Community + Financial charts

Phase 5 — Assembly
  Composite Components + Blocks + Widgets
```
